Mastering React Hooks: A Deep Dive into useEffect

Alex Rivera

Published Oct 24, 2023 • 12 min read • Updated 2 days ago

The useEffect hook is one of the most powerful yet misunderstood features in React. It allows you to perform side effects in functional components, handling everything from API calls to manual DOM mutations and subscriptions.

In the early days of React, we managed lifecycle methods like componentDidMount and componentWillUnmount. With Hooks, these concepts are unified into a single elegant function call, but with that simplicity comes a significant shift in mental model.

The Dependency Array

One of the most critical aspects of useEffect is the second argument: the dependency array. Failing to manage this properly is the leading cause of infinite loops and stale closures in modern React applications.

UserProfile.tsx 
import { useState, useEffect } from 'react';

// Fetching user data on component mount
function UserProfile({ userId }) {
  const [user, setUser] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      const response = await fetch(`/api/users/${userId}`);
      const data = await response.json();
      setUser(data);
    };

    fetchData();

    // Cleanup logic
    return () => {
      console.log('Cleaning up component');
    };
  }, [userId]); // Effect runs when userId changes

  if (!user) return <Loading />;

  return <div>{user.name}</div>;
}

Cleanup Functions

React performs the cleanup when the component unmounts. However, effects run for every completed render and not just once. This is why React also cleans up effects from the previous render before running the effects next time.

info Pro Tip

Always return a cleanup function if your effect creates a subscription, timer, or manual DOM mutation. This prevents memory leaks and inconsistent UI states.
