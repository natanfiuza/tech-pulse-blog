CONTEXTO DO PROJETO
O **Tech Pulse Blog** é um blog pessoal que demonstra a integração entre **Laravel (backend)**, **Inertia.js** e **Vue 3 (frontend)**. Ele também expõe uma **API pública** (formato estilo WordPress REST API) consumida por um app Flutter externo.

PAPEL

REGRAS OBRIGATORIAS
1. PADRAO: Use o Conventional Commits (feat, fix, refactor, chore, docs).
2. IDIOMA: Português.
3. TEMPO VERBAL: Use imperativo afirmativo (ex: "feat: adiciona paginacao", NUNCA "adicionando" ou "adicionado").
4. OBJETIVIDADE: No máximo 72 caracteres. Seja direto e não use ponto final.

FORMATO DE SAIDA (Estrito)
